# 起始页（Start Page）

> 一个部署在 [start.xrl.im](https://start.xrl.im) 的单文件浏览器起始页，整体模仿原生 macOS **Liquid Glass** 悬浮层质感。

## 这是什么

打开新标签页 / 新窗口时看到的那一屏：顶部一个居中的磨砂玻璃搜索框，底部一排玻璃质感快捷链接，叠在你自己的图片或视频背景上。零依赖、零构建，一个 `index.html` 即可运行。

## 功能一览

### 🔍 搜索
- 内置三个引擎：**千问**（默认）、**必应**、**哔哩哔哩**，胶囊形磨砂玻璃按钮切换，选中项底部有白色小圆点指示。
- 输入关键词后，**再次点击当前引擎图标**发起搜索；输入框为空时点击则进入该引擎首页。点击其他引擎只是切换，不会搜索。
- 自动记录搜索历史（最多 100 条、自动去重），输入框聚焦后用 `↑` / `↓` 翻阅。

### 🖼 背景
- **快速连续点按空白处 5 次**选择本地图片或视频作为背景，支持交叉溶解切换。
- 自动保留最近 10 个背景，用 `←` / `→` 在历史间浏览，`Enter` 把当前背景置顶。
- 全部存在浏览器本地的 IndexedDB，不依赖任何服务器，刷新与重启后仍在。
- 没设置背景时是深灰底配随机色（绿 / 粉 / 橙）的渐变波点。
- **左下角设置图标**：开启「循环播放」可在背景间自动切换（图片每 6 秒、视频播完即切）；「循环类型隔离」只切同类型；「重置」清除搜索历史与背景。

### ⚡ 快捷链接
- 随时按 `+`（输入框聚焦时除外）弹出添加面板，填入网址即可。
- 标题与图标自动从目标网页抓取（经代理），最多保存 6 个。
- 底部 dock 风格陈列：鼠标悬浮某项时，邻居会被「撑开」放大。
- **拖拽到右下角垃圾桶即可删除**，松手在别处则自动飞回原位。

### 📴 离线可用
- 注册了根作用域 Service Worker，离线也能正常打开页面并使用所有本地功能。

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓`（搜索框聚焦） | 浏览搜索历史 |
| `←` / `→` | 切换背景历史 |
| `Enter`（浏览背景时） | 把当前背景置顶 |
| `+` | 添加快捷链接 |
| `Esc` | 关闭帮助气泡 / 添加模态框 |

## 技术栈

- 单个 `index.html`：HTML + CSS + JS 全部写在一起，无构建步骤、无外部框架。
- 根作用域 Service Worker（`worker.js`）实现离线缓存与 stale-while-revalidate。
- 背景文件用 IndexedDB 持久化；偏好与快捷链接用 localStorage。
- 跨域 favicon / 网页抓取统一经代理 `https://to.ahkdxx.cn/`。

## 部署

项目通过 GitHub Pages 部署到自定义域名 `start.xrl.im`（见 `CNAME`）。把仓库推送到部署分支即可上线，无需额外配置。

## 文件结构

```
start/
├── CNAME          # start.xrl.im
├── index.html     # 单文件应用（HTML + CSS + JS）
├── worker.js      # Service Worker
├── README.md      # 项目介绍（本文件）
└── AGENTS.md      # MVP 与设计规范（给 AI agent / 协作者）
```

## 浏览器支持

主要面向现代 Chromium / Firefox / Safari。Safari 下 IndexedDB + blob URL 存在已知坑点，已做探测 + 回退处理（详见 [`AGENTS.md`](./AGENTS.md#safari-已知坑点)）。
