# PRD — 起始页（Start Page）

## 产品目标

- 为浏览器新标签页 / 新窗口提供一页极简、精致、即时可用的起始页。
- 模仿 macOS Liquid Glass 磨砂玻璃悬浮层风格，创造「漂浮在深色虚空中」的视觉体验。
- 零外部依赖（无状态管理库、无路由库），靠浏览器原生能力实现所有功能。
- 离线可用：注册 Service Worker，首次加载后即使断网也能打开。

## 用户与使用场景

- **目标用户**：使用现代浏览器的个人用户（尤其是 macOS 用户），希望新标签页比默认页更有用、更好看。
- **典型场景**：
  1. 用户打开新标签页，一眼看到搜索引擎和快捷链接，输入关键词回车即搜——中文输入法上屏时敲的那个回车不会被误当作搜索。
  2. 用户按 `←` / `→` 翻阅自己设置的多张背景，按 `Enter` 把喜欢的置顶。
  3. 用户进入 `/settings`，批量添加图片 / 视频背景，设置 6s 或 30s 循环自动轮播。
  4. 用户按 `+` 添加快捷链接，自动抓取网站标题和图标；拖拽到右下角垃圾桶删除。
  5. 用户通过手机浏览器访问起始页，搜索框和快捷链接适配小屏。

## 核心问题

1. **浏览器新标签页不可定制**：默认页要么是搜索引擎首页，要么是快速拨号，无法同时拥有搜索 + 快捷链接 + 自定义背景。
2. **背景轮播与持久化**：用户希望能设置多张背景并在它们之间浏览 / 自动切换，刷新后不丢失。
3. **快捷链接管理**：用户需要快速添加常用网站的快捷入口，且管理操作（删除）不打断使用流程。
4. **离线可用性**：作为浏览器起始页，断网时也应能打开并展示已有内容。

## 功能及其意义

| 功能 | 解决什么 | 为什么需要 |
|------|----------|------------|
| 三引擎搜索（千问 / 必应 / 哔哩哔哩，回车即搜）| 默认引擎不可选，切换搜索引擎需离开起始页 | 用户有不同的搜索习惯（问答、网页、视频），一键切换更高效 |
| 搜索历史（↑/↓ 翻阅，↑ 先取最近一条、Esc 复位、最多 100 条）| 忘记刚才搜过的内容，需要重新输入 | 减少重复输入，快速复用历史查询 |
| 自定义背景（图片 / 视频，交叉溶解切换）| 浏览器默认页视觉单一、不可定制 | 让起始页变成「自己的空间」，提升每次打开的使用愉悦感 |
| 背景历史浏览（←/→/Enter，最多 12 个）| 添加多张背景后需要快速找到喜欢的那张 | 无需进入设置页就能切换背景，操作路径极短 |
| 背景循环（6s / 30s / 不循环）| 每次打开看到同一张背景会腻 | 自动轮播保持新鲜感，视频播完自动切下一个 |
| 设置页（/settings）| 背景管理、循环设置、引擎槽位、数据清除需一个集中的管理入口 | 分离日常使用（首页）与配置（设置页），各司其职 |
| 快捷链接（最多 6 个，dock 悬停放大）| 频繁访问的网站每次都要手动输入或从书签翻找 | 一屏之内即可跳转，鼠标悬停动画提供 macOS dock 般的触感反馈 |
| 拖拽删除快捷链接 | 删除操作如果只能进设置页会很重 | 自然拖拽交互，松手即删，不打断心流 |
| 帮助气泡（? 按钮，Escape / 外点关闭）| 新用户不知道键盘快捷键 | 提供即时帮助，但不占用屏幕空间 |
| 离线可用（PWA + Service Worker）| 断网时白屏 | 起始页不应依赖网络——它是起点，即使离线也要能打开 |
| 清除所有数据（设置页标题行右侧）| 想回到全新状态时没有「一键重置」| 一键清空 localStorage、IndexedDB、Cache Storage 与 SW 注册，等效全新访客 |

## 功能之间的关系

- **首页（/）与设置页（/settings）**：首页负责日常使用（搜索、快捷链接、背景历史浏览），设置页负责配置（背景管理、循环、引擎槽位、数据清除）。两者通过 View Transitions 容器变形动画切换（齿轮气泡 ↔ 设置卡片）。
- **背景域**：由 App 常驻持有（store + media + cycle），跨路由不卸载。背景的添加、删除、设为当前只发生在 `/settings`；循环调度始终运行；首页键盘监听（←/→/Enter）依赖同一 store。
- **搜索与快捷链接**：搜索是主动行为（输入 + 回车 / 点击引擎图标），快捷链接是被动导航（点击即跳转），两者共同构成首页的两大操作单元。
- **回车是搜索的主路径**：焦点在搜索框时 `Enter` 提交搜索，焦点不在搜索框时 `Enter` 归背景历史置顶——同一个键按焦点分工，互不干扰。

## 范围与非目标

- **范围内**：
  - 搜索（三引擎 + 历史 + 默认引擎记忆）
  - 快捷链接（添加 + 自动元数据抓取 + dock 悬停 + 拖拽删除）
  - 自定义背景（添加 + 浏览 + 循环 + 删除）
  - 设置页（背景管理网格 + 循环档位 + 引擎槽位预设 + 全量数据清除）
  - 帮助气泡
  - PWA 离线 + 冷深链兜底
  - 灯塔 PWA audit 绿色

- **范围外**：
  - 用户系统 / 云端同步
  - 搜索引擎自定义（仅支持预设 + 手动三项自定义）
  - 多语言（仅简体中文）
  - 文件夹 / 分组快捷链接
  - 天气、时钟、待办等小组件
  - 浏览器扩展形式（当前仅为 Web 页面）
